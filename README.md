# Jogo do Galo — C#

## Sobre o projeto

Projeto académico desenvolvido em C# no âmbito do curso de Tecnologias e Programação de Sistemas de Informação.

O objetivo é implementar o jogo do galo, aplicando conceitos fundamentais de programação.

## Tecnologias utilizadas

- C#
- .NET
- Visual Studio

## Competências praticadas

- Lógica de programação
- Classes, objetos e métodos
- Estruturação de um projeto em C#

## Como executar

1. Clonar ou descarregar este repositório.
2. Abrir o ficheiro `jogo_do_galo.csproj` no Visual Studio.
3. Executar o projeto.

## Contexto

Projeto académico desenvolvido para consolidar conhecimentos de programação.
